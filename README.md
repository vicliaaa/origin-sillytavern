# Origin 系统（SillyTavern 扩展）

一个"系统流/穿越"扩展：悬浮面板给你（或指定角色）派任务、给积分、开商城抽奖、记成就。判定跟着正文走，不额外花 token。

## 安装
把整个 `origin` 文件夹放进：
`SillyTavern/data/<你的用户名>/extensions/origin/`
然后**完全关闭并重开** SillyTavern 页面。屏幕右下角会出现一颗悬浮球，点开即用。

## 用法
- 悬浮球：拖动移位，点开/收起面板；顶栏可切日夜。
- 任务：自动生成 / 手动添加 / 给方向让系统出；卡片可完成·编辑·删除；可设时限。
- 商城 / 背包 / 抽奖 / 成就：面板分页；商城和奖池可「一键重出」或设定每 N 回合自动更新。
- 设置页（⚙）：频率、时限范围、奖惩偏好、第四面墙几率、模块开关、系统名/人格、主色、
- 反串模式：设置顶「系统绑定对象」填一个角色名，系统就归该角色（他有系统、你旁观）。
- 在正文里直接对系统说话（"系统，…"），它会用设定的人格回应。

## 存档
每局聊天独立存档；分叉/划楼有逐楼快照，状态跟着剧情走。数据只存本地聊天文件，不进 token。
